Dokumentasi Teknis Capstone (4 Mata Kuliah)

1. Pemetaan 5 Atribut Kualitas Perangkat Lunak (FURPS):

  • Functionality: Ekstraksi OCR akurat, deteksi bounding box per wilayah surat, validasi regex nomor, PUEBI, stempel, dan tanda tangan.
  • Usability: Antarmuka Split-Screen interaktif dengan fitur sinkronisasi klik-ke-fokus (Click-to-Focus) dan rekomendasi perbaikan instan.
  • Reliability: Robust terhadap kemiringan dokumen (deskewing) dan pencahayaan buruk dengan filter adaptive threshold.
  • Performance: Pipeline inferensi ultra-responsif (<300ms) dengan arsitektur non-blocking.
  • Supportability: Aturan validasi tersentralisasi dalam rule engine berbasis preset JSON yang mudah diperluas tanpa modifikasi UI.

2. Rencana Pembagian Tugas Kelompok (WBS - MPTI):

Anggota 1 (Project Manager & Integration): Manajemen Sprint, WBS, arsitektur REST API & deployment.

Anggota 2 (Computer Vision & DL): Pipeline OpenCV (deskewing, filtering), training YOLOv8 DocLayNet & PaddleOCR.

Anggota 3 (Frontend & Usability): Canvas 2D interactive viewer, SVG overlay bounding boxes, dan responsive design.

Anggota 4 (NLP & QA/Testing): Rule engine regex, pengujian Blackbox, Unit testing, dan kuesioner evaluasi SUS.
